AI-Powered Mock Interview Platform

An AI-powered web application designed to help students prepare for technical and HR interviews.

Features

- User registration and login
- Admin dashboard
- Interview question management
- AI-based interview preparation
- Interview performance evaluation

Technologies Used

- Frontend: React, Vite, CSS
- Backend: Node.js, Express
- Database: MongoDB
- AI Integration: AI API

Project Structure

- "client/" – Frontend application
- "scripts/" – Backend scripts
- "src/" – Backend source code
- "test/" – Test files

Installation

Install dependencies in the client and server directories.
